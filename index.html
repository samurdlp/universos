Sincronización en la Nube

Introduce tu identificador y contraseña para sincronizar tus apuntes entre ordenador, tablet y móvil.

Deriva una clave criptográfica única (SHA-256) para que nadie pueda leer ni sobrescribir tu ID.
Ver SQL para crear la tabla en Supabase 
create table universos_sync (
  id text primary key,
  data jsonb,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);
alter table universos_sync enable row level security;
create policy "Acceso universos" on universos_sync for all using (true);
