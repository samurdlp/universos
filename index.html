☁️ Sincronización en la Nube

Conecta UniverSOS con tu proyecto gratuito de Supabase para tener tus apuntes sincronizados en tu portátil, tablet y móvil.

Usa el mismo código en todos tus dispositivos para compartir los mismos apuntes.
📋 Ver SQL para crear la tabla en Supabase (1 clic) 
create table universos_sync (
  id text primary key,
  data jsonb,
  updated_at timestamp with time zone default timezone('utc'::text, now())
);
alter table universos_sync enable row level security;
create policy "Acceso público universos" on universos_sync for all using (true);
